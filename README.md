# Што гэта?
Беларуская PC-раскладка для macOS. У bundle няма іншых варыянтаў раскладкі.

У macOS Tahoe раскладка выкарыстоўвае індыкатар `БЕ` — літары, выразаныя (празрыстыя) у скругленым значку-клавішы. У радку меню значок сам мяняе колер пад светлую і цёмную тэму. У панэлі пераключэння моў Tahoe малюе значок як ёсць, без інверсіі — сістэма там губляе сцяг `TISIconIsTemplate` (гэта памылка macOS). Таму літары наўмысна не маюць уласнага колеру: праз іх відаць фон, і яны аднолькава чытаюцца на цёмнай панэлі, на светлай і на блакітным вылучаным радку. Убудаваныя індыкатары Apple крыху шырэйшыя (22×16), бо бяруцца з сістэмнай табліцы, даступнай толькі раскладкам Apple, таму карыстальніцкі значок квадратны (16×16).

# Як паставіць?
- Адкрыць *Belarusian.dmg*, двойчы клікнуць на *Belarusian.bundle* і ўсталяваць раскладку
- Альтэрнатыўны шлях: перанесці *Belarusian.bundle* у *~/Library/Keyboard Layouts*
- Выйсці з уліковага запісу і ўвайсці зноў, асабліва пры абнаўленні старой версіі
- У *System Settings → Keyboard → Text Input → Edit* дадаць менавіта *Беларуская — ПК*. Убудаваная раскладка *Беларуская* — іншая і па-ранейшаму паказвае сцяг
- **UPDATE 20.09.2021:** High Sierra і ранейшыя сістэмы лавілі баг з прамой усталёўкай праз *.bundle* файл, можна карыстацца файлам *keyboard installer*, абраць там адпаведную опцыю (install for all users), працуе ў тым ліку з апошняй версіяй раскладкі
